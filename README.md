# Usage Finder

A native macOS app that shows your Mac's usage live: CPU load per core (Performance and Efficiency clusters), load average, memory and swap, memory pressure, system power and battery. Keep it in the menu bar as compact live meters, or open the window for history charts.

This repository hosts the signed and notarized downloads.

## Download

**[Download the latest version](https://github.com/ekramjim/UsageFinder-Releases/releases/latest/download/UsageFinder.dmg)** · [All releases](https://github.com/ekramjim/UsageFinder-Releases/releases)

Requires macOS 26 or later (Apple silicon or Intel).

1. Open `UsageFinder.dmg`.
2. Drag **Usage Finder** to **Applications**.
3. Open it from Applications. The live meters appear in the menu bar.

## Updates

Usage Finder updates itself. Open **Settings → General → Check for Updates…**, or let it check automatically once a day. Every update is signed, notarized by Apple, and verified before it installs.

A Mac App Store edition is also in public beta on TestFlight.

## Privacy

Usage Finder reads system statistics locally on your Mac. It collects no data and sends nothing anywhere; the only network request is the daily update check.
